Credit Risk Assessment System

An end-to-end machine learning system for assessing loan default risk with calibrated probability estimation and explainable credit decisioning.

01 Architecture

XGBoost Classifier

Trained on credit records with median imputation, one-hot encoding, and hyperparameter tuning for class imbalance.

02 Decision Boundary

Classification Threshold

Optimized decision cutoff derived from Precision-Recall curve analysis to balance loan approvals and default risk.

03 Reliability

Probability Calibration

Calibrated via 5-fold cross-validated sigmoid scaling (CalibratedClassifierCV) ensuring probabilities reflect true odds.

04 Interpretability

SHAP Explainability

TreeExplainer framework delivering global feature rankings and individual waterfall attribution per applicant.
